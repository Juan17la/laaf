# Minigames & Economy — LAAF

Minigames are the **fun break** between hunts and the main source of money. Money buys better stats, weapons and supplies from Grady. They are **optional**: the game can be finished without them, but it is harder.

## 1. Currency — Lantern Tokens

- Old brass tokens from the Lantern Festival (the town stopped using real money under The Veil).
- **Sources:** minigames (main), searching drawers/stashes, knocked‑out Marked Ones, helping marked townspeople, selling fish.
- **Sinks:** Grady's shop (upgrades, weapons, supplies), card game bets, losing 50% when **Taken**.
- Tokens are shown in the HUD only when they change or in the hub.

## 2. Minigame rules (all)

- Each minigame is placed in a **story‑fitting location**.
- Each has a **daily limit** (resets when sleeping in the motel) so they can't be farmed forever.
- Most produce **noise**; playing at night in a zone can attract the zone's hunter. The noise radius is shown on the minigame UI.
- The player can **quit anytime** (Esc / B) — progress in that round is lost, nothing else.
- Difficulty scales with the chapter and with repeat plays in the same day.
- A **first‑time win** of every minigame gives a bonus (tokens + a lore note).

## 3. Minigames

### 3.1 Lockpicking
| Field | Value |
|---|---|
| Location | Locked doors, cabins, lockers, safes, pharmacy cabinet, motel Room 4 |
| Mechanic | Rotate the pick (mouse / left stick) to find the sweet spot, then turn the cylinder (A/D or triggers). Pin tension bar; too much → pick breaks |
| Tiers | Simple (1 pin), Medium (2 pins), Hard (3 pins, moving sweet spot) |
| Rewards | Stash contents: 10–60 tokens, supplies, evidence, key items |
| Cost | Bobby pins (consumable, bought or found) |
| Noise | 3 m per broken pick |
| Limit | None (limited by stashes and pins) |
| Upgrade link | "Steady Hands" upgrade widens the sweet spot |

### 3.2 Fishing
| Field | Value |
|---|---|
| Location | Harbor fishing dock (day only), lake shore by the motel |
| Mechanic | Cast (hold to charge distance) → wait for bite (controller vibrates / float dips) → reel with a **tension bar**: keep the marker in the green zone while the fish pulls. Too much tension = line snaps |
| Catch table | Perch (5 tokens), Trout (12), Pike (25), Lake Eel (40, night only), **"Old Tom"** legendary catfish (150, one time, lore about Tomás) |
| Also catch | Junk (bottles for throwing), sunken boxes with supplies or evidence #10 |
| Sell | Grady buys fish; or cook one → small heal item |
| Noise | Low (2 m); reeling a big fish 8 m |
| Limit | 10 casts per day |

### 3.3 Arcade cabinet — "Moth Run"
| Field | Value |
|---|---|
| Location | Diner next to the Lakeview Motel (safe area) |
| Mechanic | 2D endless runner inside the game: a moth flies between lanterns avoiding hands reaching from the dark. Score by distance and lanterns touched |
| Rewards | 1 token per 100 points (max 60 per day). High score table with fake town names (Lily V., Tomás R., Sam K. — story easter eggs) |
| Secret | Beating 10,000 points reveals a message from Elena on the high‑score screen |
| Cost | 1 token per play |
| Noise | 15 m (loud machine) — only safe by day |
| Limit | 60 tokens per day |

### 3.4 Card game — "Lantern Hi‑Lo"
| Field | Value |
|---|---|
| Location | The Drowned Lantern bar, against **Silas** |
| Mechanic | Hi‑Lo with a twist: a card is shown; bet whether the next is higher or lower. Chain correct guesses to multiply the bet (x1.5, x2, x3). Cash out anytime. A **Veil card** (joker) makes you lose the chain |
| Bets | 5 / 20 / 50 tokens. High‑stakes table unlocks in Chapter 5 |
| Rewards | Bet × multiplier. Beating the high‑stakes table 3 times wins **evidence #12** (Shepherd's letter) |
| Risk | Can lose tokens — the only minigame with real loss |
| Silas | Gives rumors when he's winning (hints about hunters' routes) |
| Limit | 10 hands per day |

### 3.5 Shooting gallery
| Field | Value |
|---|---|
| Location | Festival grounds (town square) |
| Mechanic | Old festival stall with moving tin targets (moths, lanterns, crows). 60 seconds. Hitting a "Veil eye" target subtracts points |
| Rewards | 10–50 tokens by score; **trains Aim stat** (up to 3 levels by reaching score thresholds) |
| Cost | 3 tokens per round (uses stall ammo, not player ammo) |
| Noise | 20 m — attracts Marked Ones at night |
| Limit | 5 rounds per day |

### 3.6 Radio tuning
| Field | Value |
|---|---|
| Location | Motel Room 6 radio; lighthouse radio room (after Chapter 3) |
| Mechanic | Turn the frequency dial and the fine‑tune knob to clean a signal (waveform matches a target shape). Time limit before the signal fades |
| Signals | Elena's messages (story), The Shepherd's broadcasts (lore), coded numbers (open stashes with tokens), music (unlocks tracks) |
| Rewards | 15–40 tokens via stash codes, lore, **evidence #9** (Elena's hidden recording) |
| Noise | 4 m |
| Limit | 3 new signals per day |

## 5. Economy balance targets

| Point in game | Expected tokens earned (total) | Expected purchases |
|---|---|---|
| End of Chapter 2 | ~150 | 1–2 tier‑1 upgrades + supplies |
| End of Chapter 5 | ~900 | Most tier‑1, some tier‑2, revolver |
| End of Chapter 7 | ~1,800 | Tier‑2 across the board, 2–3 tier‑3 |
| Completionist (all minigames daily) | ~2,600 | Nearly everything |

- Minigames should give ~60% of total tokens; exploration ~40%.
- A player who ignores minigames can still finish on Normal with tier‑1 upgrades and good stealth.
